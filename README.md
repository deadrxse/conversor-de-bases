# Conversor de Bases Numéricas



Projeto desenvolvido em **C++**, utilizando o ambiente Dev-C++.



## Sobre o projeto



Este programa permite converter números entre diferentes bases numéricas por meio de um menu interativo.



## Funcionalidades



- Conversão de binário para decimal.

- Conversão de decimal para binário, octal e hexadecimal.

- Conversão de octal para decimal.

- Conversão de hexadecimal para decimal.

- Validação de entradas.

- Tratamento de números que ultrapassam o limite do tipo `int`.



## Tecnologias utilizadas



- C++

- Dev-C++



## Como utilizar



1. Compile e execute o programa.

2. Escolha uma opção no menu.

3. Digite o número que deseja converter.

4. Visualize o resultado da conversão.

5. Digite `0` no menu para encerrar o programa.



## Objetivo



Projeto desenvolvido para praticar conceitos fundamentais de programação em C++, como funções, estruturas condicionais, laços de repetição, strings e operações matemáticas.
